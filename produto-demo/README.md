# Protótipo de produto (não comercial)

O diretório `produto-demo/` contém um exemplo visual original para validar a ideia.

**Ainda não é um produto completo para venda.** Antes de publicar:

1. Desenvolver arquivos editáveis de qualidade comercial (não apenas SVG demonstrativo).
2. Conferir textos, fontes utilizadas, licenças de imagens, formatos e acessibilidade.
3. Gerar e testar os ZIPs finais e carregá-los no bucket PRIVADO `digital-products` do Supabase.
4. Associar cada item ao Price ID correto do Stripe.
5. Ativar `ENABLE_CHECKOUT=true` somente após teste de compra e download.
